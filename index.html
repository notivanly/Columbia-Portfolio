Build a bridge from wood, steel, concrete, cable or carbon fiber, then send vehicles across it and see what holds.

Try Pick the Pratt Truss template and turn on Force Diagram.

Open simulator: Bridge Physics Simulator (opens in a new tab)
How it works

Preview. A separate 3D truss bridge with a moving vehicle, drawn for this page. Each bar is shaded by the force in it: plain bars are in tension and bars drawn as broken segments are in compression. It is not the bridge game. The exploded view on the home screen is decorative.

02

Mini Wind Tunnel Simulator

Adjust speed, angle, air density and wing area and watch streamlines flow around the wing as lift and drag update.

Try Push the angle past 15 degrees to see the wing stall.

Open simulator: Mini Wind Tunnel Simulator (opens in a new tab)Source code: Mini Wind Tunnel Simulator on GitHub (opens in a new tab)
How it works

Preview. A separate drawing of airflow around a wing, not output from the simulator. The wing is given depth and a glass tunnel for effect; the flow is in one plane.

On the page. Controls for wind speed, angle of attack, air density and wing area, with readouts for lift, drag and the lift-to-drag ratio.

Model. L = ½ρV²S·CL and D = ½ρV²S·CD. CL rises by 2π per radian up to 15 degrees. Past that, a simple stall rule removes 5.5 percent of the stall value per degree, down to a floor of 35 percent. Drag is CD = 0.02 + 0.05·CL².

Streamlines. They come from potential flow around a Joukowski airfoil, with the circulation set to match the lift coefficient.

Limits. The constants are assumed values for teaching, not measured data. It is not CFD, so there is no viscosity or flow separation.

03

Truss Force Analyzer

Draw a 2D truss, add supports and loads, and see each member’s force as tension or compression.

Try Load an example, then press Analyze.

Open simulator: Truss Force Analyzer (opens in a new tab)Source code: Truss Force Analyzer on GitHub (opens in a new tab)
How it works

Preview. A separate truss with a moving load, drawn for this page. Plain bars are in tension and hatched bars are in compression. It is not the analyzer.

On the page. The deformed shape is drawn magnified so you can see how the structure moves.

Model. K u = F. The solver builds a stiffness matrix for a pin-jointed 2D truss, solves it by Gaussian elimination for how far each joint moves, then turns each member’s change in length into an axial force. Tension is positive and compression negative. It handles determinate and indeterminate trusses.

Checks. It compares members plus reactions against twice the number of joints and reports an unstable truss instead of returning numbers. A singular stiffness matrix is flagged the same way. Results can be exported as CSV.

Limits. Members are linear elastic and share one axial stiffness, EA, and displacements are small. It does not check member strength or buckling.

04

Physics Sandbox

Drop, throw and connect shapes in a 2D playground with gravity, collisions, friction, springs and pendulums.

Try Open Newton’s cradle, then change gravity.

Open simulator: Physics Sandbox (opens in a new tab)Source code: Physics Sandbox on GitHub (opens in a new tab)
How it works

Preview. Circles, a pendulum, rods and a spring in a separate animation, not scenes from the simulator.

Implementation. A rigid-body engine for circles and convex polygons. Collisions are found with the separating axis test. When two shapes touch, an impulse j along the contact changes their velocities, v′ = v + j/m, so they stop moving into each other. Contacts are solved with sequential impulses that include friction and warm starting, and each step is split into substeps.

Joints. Hinge, rod, rope and spring.

Limits. It is 2D only and has no continuous collision detection, so very fast objects can pass through thin ones.

05

Planetary Gravity Explorer

Compare gravity and escape velocity across the eight planets, then drop or jump on each one.

Try Drop an object on Mars, then on Jupiter.

Open simulator: Planetary Gravity Explorer (opens in a new tab)Source code: Planetary Gravity Explorer on GitHub (opens in a new tab)
How it works

Preview. A sheet bends around masses as an analogy. Sizes and spacing are not to scale, and nothing in it is simulator output.

On the page. Surface gravity, escape velocity and weight for each of the eight planets, plus a gravity lab for drops and jumps.

Model. Each planet is defined by its gravitational parameter GM and radius. Surface gravity is g = GM/R², escape speed is v = √(2GM/R), and weight is W = mg. Drops and jumps use constant acceleration with no air resistance.

Limits. Reference values are approximate. For the gas and ice giants the radius is the 1-bar level, which is what the usual reference gravities assume.

Orbital Mechanics Simulator

Pick a world, set an altitude and speed, launch a spacecraft, and fly the orbit with prograde and retrograde burns.

Try Start with the Circular preset, then burn prograde.

Open simulator: Orbital Mechanics Simulator (opens in a new tab)Source code: Orbital Mechanics Simulator on GitHub (opens in a new tab)
How it works

Preview. It shows a transfer between two circular orbits. In the simulator you set the altitude and speed yourself.

On the page. Choose Earth, Mars or the Moon, then set an altitude and a starting tangential speed.

Model. Two-body gravity, a = −GM r / |r|³, advanced with a fourth-order Runge-Kutta integrator. The dashed path is the exact conic orbit for the current state, found with the vis-viva equation. Burns change the speed along the direction of travel.

Limits. No atmosphere, no other bodies, and the spacecraft is a point mass. It is not for mission planning.

AMC Practice

Timed AMC 8, 10 and 12 mock tests, problems by topic, drills with worked solutions, and progress tracking.

Try Start a mock test and review every question afterward.

Explore tool: AMC Practice (opens in a new tab)Source code: AMC Practice on GitHub (opens in a new tab)
How it works

Preview. A drawing of a geometry construction with an answer strip. It is not a screenshot of the site and not a real AMC problem.

Title. It is titled AMC Arena on the page.

Content. 133 AMC-style problems across algebra, geometry, number theory, and counting and probability, plus generated drills.

Scoring. The AMC 8 scores 1 point per correct answer. The AMC 10 and 12 score 6 for a correct answer, 1.5 for a blank and 0 for a wrong answer.

Implementation. A static site with no server. Progress is saved in your browser’s local storage, and math is drawn with KaTeX. The problem bank is written in Python and built into problems.js by a script that checks each problem has five choices and a valid answer.

Note. It is an unofficial practice site, not affiliated with or endorsed by the Mathematical Association of America.

Calculus III Visualizer

Graph a function of x and y as a 3D surface and explore its tangent plane, gradient and level curves.

Try Type your own function, then click the surface.

Explore tool: Calculus III Visualizer (opens in a new tab)Source code: Calculus III Visualizer on GitHub (opens in a new tab)
How it works

Preview. A drawing of a surface with its level curves, tangent plane and gradient, not a screenshot of the tool.

Implementation. Built with Three.js, loaded from a CDN. The functions you type are read by a small expression parser, and the surface is sampled on a 120 by 120 grid. The page notes that derivatives are computed numerically.

Gradient. The gradient is the pair of partial derivatives, (fx, fy), drawn as an arrow on the function you typed. Moving the point shows how the arrow and the tangent plane change.

Vector fields. You enter the components P, Q and R of a field, which is drawn as arrows with animated flow and a probe point. The page also covers divergence and curl.

Limits. It needs an internet connection to load Three.js.
