02 / 09Physics and engineeringSimulator

Mini Wind Tunnel Simulator

Change wind speed, angle of attack, air density and wing area, then watch streamlines move around a wing while lift, drag and the lift-to-drag ratio update.

Try thisRaise the angle of attack past about 15 degrees and watch the lift coefficient fall as the wing stalls.

Open simulator: Mini Wind Tunnel Simulator (opens in a new tab)Source code: Mini Wind Tunnel Simulator on GitHub (opens in a new tab)
Technical details

Model. Lift and drag use L = ½ρV²S·CL and D = ½ρV²S·CD. CL rises by 2π per radian up to 15 degrees. Past that, a simple stall rule removes 5.5 percent of the stall value per degree, down to a floor of 35 percent. Drag is CD = 0.02 + 0.05·CL².

Streamlines. They come from potential flow around a Joukowski airfoil, with the circulation set to match the lift coefficient.

Limits. The constants are assumed values for teaching, not measured data. It is not CFD, so there is no viscosity or flow separation.

03 / 09Physics and engineeringSimulator

Truss Force Analyzer

Draw a 2D truss, place supports and loads, and see the force in every member as tension or compression, along with how the structure deforms.

Try thisLoad an example, press Analyze, and compare which members are in tension and which are in compression.

Open simulator: Truss Force Analyzer (opens in a new tab)Source code: Truss Force Analyzer on GitHub (opens in a new tab)
Technical details

Model. The solver builds a stiffness matrix for a pin-jointed 2D truss, solves K u = F by Gaussian elimination, and gets each member’s axial force from its change in length. It handles determinate and indeterminate trusses.

Checks. It compares members plus reactions against twice the number of joints and reports an unstable truss, instead of returning numbers. A singular stiffness matrix is flagged the same way. Member results can be exported as CSV.

Assumptions. Members are linear elastic and share one axial stiffness, EA. Displacements are small, and the deformed shape is drawn magnified.

Limits. It does not check member strength or buckling.

04 / 09Physics and engineeringSimulator

Physics Sandbox

Drop, throw and connect shapes in a 2D physics playground with gravity, collisions, friction, springs and pendulums.

Try thisOpen the Newton’s cradle scene, then switch gravity to the Moon or Jupiter and compare.

Open simulator: Physics Sandbox (opens in a new tab)Source code: Physics Sandbox on GitHub (opens in a new tab)
Technical details

Implementation. A rigid-body engine for circles and convex polygons. Collisions are found with the separating axis test, and contacts are solved with sequential impulses that include friction and warm starting. Each step is split into substeps.

Joints. Hinge, rod, rope and spring.

Limits. It is 2D only and has no continuous collision detection, so very fast objects can pass through thin ones.

05 / 09Physics and engineeringSimulator

Planetary Gravity Explorer

Compare surface gravity, escape velocity and weight across the eight planets, then drop or jump on each one to see how the same motion changes.

Try thisOpen the gravity lab, drop an object on Mars, then try Jupiter and compare the fall times.

Open simulator: Planetary Gravity Explorer (opens in a new tab)Source code: Planetary Gravity Explorer on GitHub (opens in a new tab)
Technical details

Model. Each planet is defined by its gravitational parameter GM and its radius. Surface gravity is g = GM/R², escape speed is v = √(2GM/R), and weight is mg.

Drops and jumps. They use constant-acceleration motion with no air resistance.

Limits. Reference values are approximate. For the gas and ice giants the radius is the 1-bar level, which is what the usual reference gravities assume.

06 / 09Physics and engineeringSimulator

Orbital Mechanics Simulator

Choose Earth, Mars or the Moon, set an altitude and a starting speed, launch, and then fly the orbit with prograde and retrograde burns.

Try thisPick the Circular preset, launch, then add a prograde burn and watch the orbit stretch into an ellipse.

Open simulator: Orbital Mechanics Simulator (opens in a new tab)Source code: Orbital Mechanics Simulator on GitHub (opens in a new tab)
Technical details

Model. Two-body gravity between the spacecraft and one planet or moon. Motion is advanced with a fourth-order Runge-Kutta integrator. The dashed path is the exact conic orbit for the current state, found with the vis-viva equation.

Burns. Prograde and retrograde burns change the speed along the direction of travel.

Limits. No atmosphere, no other bodies, and the spacecraft is a point mass. It is not for mission planning.

08 / 09MathematicsWeb tool

AMC Practice

Practice for the AMC 8, 10 and 12 with timed mock tests, problems by topic and difficulty, endless drills with worked solutions, and progress tracking. It is titled AMC Arena on the page.

Try thisStart a mock test, mark your answers on the answer sheet, flag a question, then review every question afterward.

Explore tool: AMC Practice (opens in a new tab)Source code: AMC Practice on GitHub (opens in a new tab)
Technical details

Content. 133 AMC-style problems across algebra, geometry, number theory, and counting and probability, plus generated drills.

Scoring. The AMC 8 scores 1 point per correct answer. The AMC 10 and 12 score 6 for a correct answer, 1.5 for a blank and 0 for a wrong answer.

Implementation. A static site with no server. Progress is saved in your browser’s local storage, and math is drawn with KaTeX. The problem bank is written in Python and built into problems.js by a script that checks each problem has five choices and a valid answer.

Note. It is an unofficial practice site, not affiliated with or endorsed by the Mathematical Association of America.

09 / 09MathematicsWeb tool

Calculus III Visualizer

Graph a function of two variables as a 3D surface and explore its tangent plane, partial-derivative slices, gradient and level curves. A second tab draws 3D vector fields with animated flow and covers divergence and curl.

Try thisType your own function of x and y, then click the surface to move the point and watch the tangent plane and gradient follow.

Explore tool: Calculus III Visualizer (opens in a new tab)Source code: Calculus III Visualizer on GitHub (opens in a new tab)
Technical details

Implementation. Built with Three.js, loaded from a CDN. The functions you type are read by a small expression parser, and the surface is sampled on a 120 by 120 grid. The page notes that derivatives are computed numerically.

Vector fields. You enter the components P, Q and R of a field, which is drawn as arrows with animated flow and a probe point. The page also covers divergence and curl.

Limits. It needs an internet connection to load Three.js.

Engineering

From equations to working programs

Each project turns a rule from physics or mathematics into something you can change with a slider or a click. These examples show how that looks in the tools above. Every project is different, so this is not a fixed recipe.

  1. K u = F

    Truss Force Analyzer

    The analyzer assembles a stiffness matrix from the joints and members, solves for how far each joint moves, then turns each member’s change in length into an axial force. Tension comes out positive and compression negative.

  2. a = −GM r / |r|³

    Orbital Mechanics Simulator

    Every step, the simulator computes the pull of gravity on the spacecraft and advances position and velocity with a fourth-order Runge-Kutta integrator. A burn simply changes the velocity, and the orbit that follows is the program’s answer.

  3. g = GM / R²

    Planetary Gravity Explorer

    One formula gives each planet’s surface gravity, and a second gives escape speed. The drop and jump demonstrations then apply constant acceleration, which is why the same jump goes so much higher on Mars.

  4. L = ½ρV²S·CL

    Mini Wind Tunnel Simulator

    Sliders set speed, density, area and angle, and the lift equation turns them into a force. The lift coefficient follows a simple rule that rises with angle and then falls at stall, so the stall is a modeling choice, not a measurement.

  5. v′ = v + j / m

    Physics Sandbox

    When two shapes touch, the engine applies an impulse along the contact so they stop moving into each other. Friction, springs and joints are more of the same idea, repeated over many small steps.

  6. ∇f = (fx, fy)

    Calculus III Visualizer

    The gradient is a pair of partial derivatives, and the tool draws it as an arrow on the function you typed. Moving the point shows how the arrow and the tangent plane change from place to place.
